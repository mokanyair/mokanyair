### 3. AWS Event-Driven Serverless Architecture

**Project:**  
Designed an AWS serverless infrastructure platform using event-driven architectural principles and Terraform-based Infrastructure as Code.

**Problem It Solves:**  
Demonstrates how cloud workloads can be decoupled from continuously running infrastructure by using event-driven compute and reusable Infrastructure-as-Code patterns, improving deployment repeatability and reducing infrastructure management overhead.

**Architecture:**  
Event Source → AWS Event Processing → Lambda Compute → Downstream Cloud Services, with the supporting infrastructure provisioned and managed through reusable Terraform modules.

**Technologies:**  
AWS | AWS Lambda | Terraform | Infrastructure as Code | Event-Driven Architecture | Serverless Computing | Terraform Modules | Remote State

**What I Personally Designed:**  
Designed the serverless architecture, Lambda execution components, Terraform root configuration, reusable infrastructure modules, provider configuration, variables/outputs and remote-state/backend structure.

**Reliability / Security / Scale Focus:**  
Loose coupling, stateless compute, independently scalable components, repeatable infrastructure provisioning, modular IaC and reduced infrastructure-management overhead.
